# Safety

Safety is an independent engine. It does not consume or reinterpret the ordinary item score. The current prototype uses a conservative phrase gate only to stop adaptive clarification and return `SAFETY_REVIEW`; the event is persisted as `HUMAN_REVIEW` with a review case, not treated as an automated crisis intervention.

The psychology team must define and approve the production trigger vocabulary, escalation channel, response copy, and audit/retention policy before deployment. Until then the app must be labelled a research prototype.
